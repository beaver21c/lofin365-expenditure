데이터가 아직 생성되지 않았습니다

대시보드 화면은 준비되어 있지만, 표시할 집계 데이터가 없습니다. 저장소에서 2. 대시보드 빌드 및 배포 워크플로를 한 번 실행하면 채워집니다.

  1. 토큰 등록 — 원자료가 비공개 저장소에 있어 읽기 토큰이 필요합니다. SOURCE_REPO_TOKEN 을 저장소 Secrets 에 등록합니다.
  2. 측정 — 1. 원자료 측정 을 실행해 데이터 규모를 확인합니다.
  3. 빌드 — 2. 대시보드 빌드 및 배포 를 실행합니다.

자세한 절차는 저장소의 docs/SETUP.md 에 있습니다.
